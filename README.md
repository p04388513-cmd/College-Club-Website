# College Club Website

A simple responsive college club website built with HTML, CSS, and JavaScript.

## Sections
- Home
- About Club
- Members
- Activities
- Events
- Contact

## Features
- Responsive desktop, tablet, and mobile layout
- Mobile navigation
- Dark/light mode
- Smooth scrolling
- Scroll reveal animations
- Upcoming and past event cards
- Member profiles
- Social media links
- No external libraries or build tools required

## How to Run
1. Extract the ZIP.
2. Open `index.html` in a modern web browser.
3. Replace the sample club name, member names, events, email, phone number, and social links with actual club details.

## Files
- `index.html` — website structure and content
- `style.css` — styling and responsive design
- `script.js` — navigation, theme toggle, and animations
